# Root Cause Analysis (RCA) Template for Healthcare

## 1. Purpose

Use this template to investigate a healthcare quality or patient safety problem, identify contributing factors, and plan actions to reduce the risk of recurrence.

RCA should focus on understanding how the system contributed to an event, rather than assigning blame to individuals.

## 6. Root Cause Exploration: Five Whys

Start with the clearly defined problem. Ask “Why?” repeatedly to explore underlying system factors. Verify each answer with evidence.

1. **Why did the problem occur?**
2. **Why did that contributing factor occur?**
3. **Why was the issue not prevented or detected earlier?**
4. **What system or process weaknesses contributed?**
5. **What evidence supports the proposed root causes?**

The Five Whys is one exploratory method, not proof that every problem has a single root cause.

## Important Considerations

- Protect confidentiality and follow applicable privacy requirements.
- Use verified information and document uncertainty.
- Follow local incident-reporting policies and escalation procedures.
- Involve relevant staff and, where appropriate, patients or families.
- RCA is a structured learning approach; it does not replace a formal investigation when one is required.
